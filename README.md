# Mi App Node

Este es un proyecto sencillo en Node.js que renderiza una página web con un mensaje de prueba.

## Estructura del Proyecto

```
mi-app-node
├── src
│   ├── index.js          # Punto de entrada de la aplicación
│   └── views
│       └── index.html    # Página HTML que se renderiza
├── package.json          # Archivo de configuración de npm
└── README.md             # Documentación del proyecto
```

## Requisitos

Asegúrate de tener [Node.js](https://nodejs.org/) instalado en tu máquina.

## Instalación

1. Clona el repositorio o descarga el código fuente.
2. Navega al directorio del proyecto:
   ```
   cd mi-app-node
   ```
3. Instala las dependencias:
   ```
   npm install
   ```

## Ejecución

Para iniciar la aplicación, ejecuta el siguiente comando:
```
npm start
```

Luego, abre tu navegador y visita `http://localhost:3000` para ver el mensaje de prueba.
